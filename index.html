02 / GENERADOR DE GRAFICAS

Visualizador de datos externos

CSV · XLS · XLSX

Carga un archivo local para comparar dos columnas en una gráfica por ejemplo "titulo" y "precio".

Formatos permitidos: CSV, XLS y XLSX.

Guía rápida

Eje X
Es el eje horizontal. Selecciona un campo descriptivo o identificador, como Nombre, SKU, ID o Código.
Eje Y
Es el eje vertical y necesita valores numéricos, como Precio, Stock, Ventas o Puntuación.
Ordenar
Usa Menor a mayor o Mayor a menor para ordenar por el eje Y, o conserva el orden original del archivo.
Categoría, filtrar y agrupar
Selecciona una columna con categorías repetidas para segmentar los datos o agruparlos y obtener un promedio por categoría.
Zoom y desplazamiento
Usa los botones de lupa para acercar o alejar la vista. También puedes desplazarte horizontalmente sobre el eje X y restablecer la vista.
